How to Install Extension from GitHub

A simple, step-by-step guide to installing unpacked Chrome extensions.

1

Go to Releases

Open the GitHub repository page and click on the latest version link under Releases on the right sidebar.

2

Download the File

Scroll down to the Assets section on the release page and download Chromium.zip.

3

Extract the Zip File

Locate the downloaded zip file, right-click it, and select 7-Zip > Extract Here (or your preferred extractor).

4

Confirm Extraction

Click OK on the extraction window to unpack the files onto your device.

5

Check Folder Contents

Open the extracted folder to ensure you see the extension files (such as manifest.json and code files).

6

Open Chrome Extensions

Open Google Chrome, type chrome://extensions into the address bar, turn on Developer mode (top right), and click Load unpacked.

7

Select the Unpacked Folder

Navigate to your extracted Chromium folder, select it, and click Select Folder.

8

Installation Complete

Your extension is now installed and ready to use!
