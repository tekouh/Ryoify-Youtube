Install Chrome Extensions from GitHub

A super simple, step-by-step guide.

1

Find the Releases

On the extension's GitHub page, look at the right sidebar and click on the Latest Release.

2

Download the File

Under the "Assets" section, click to download the Chromium.zip file to your computer.

3

Extract the Zip

Right-click the downloaded zip file. Use your zip program (like 7-Zip) and select "Extract Here".

Note: Avoid "Extract files..." to prevent messy folders.

4

Check the Folder

You should now have a folder named Chromium. If you open it, it should look like this, containing files like `manifest.json`.

5

Open Chrome Extensions

Type chrome://extensions in your Chrome URL bar and press Enter.

  • Turn on Developer mode (top right).
  • Click the Load unpacked button (top left).
6

Load the Folder

A window will appear. Find and select the Chromium folder you extracted earlier, then click Select Folder.

Tip: If there's a folder inside the folder, make sure to select the one containing the actual files.

✓

You're Done!

The extension should now appear in your list and is ready to use.
